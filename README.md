## 🌌 About Melodika
Melodika is not just another music player; it's a high-fidelity offline audio engine wrapped in an ultra-minimalist, flagship-grade user interface. Designed specifically for music lovers who appreciate clean aesthetics, Melodika offers a pure, ad-free listening experience with advanced library management.

Built with **0% Technical Debt**, it strictly follows Android's recommended MVVM architecture to ensure buttery-smooth gesture transitions and flawless state management.

## ✨ Signature Features

### 🎨 Pure Pitch-Black & Glassmorphism UI
Designed specifically for OLED screens. Melodika utilizes true pitch-black backgrounds paired with elegant, semi-transparent frosted glass effects to make your album art pop. 

### 🎤 Word-Level Lyric Synchronization
Experience music like never before. Melodika features a custom-built, studio-grade lyric synchronization system that highlights lyrics perfectly in time with the audio track.

### 🗂️ Intelligent Library & Folder-Wise Browsing
Take absolute control of your local files. Browse your library by songs, artists, albums, or dive directly into your device's internal folders. Includes a powerful batch-operation engine for multi-selection, sharing, and deleting.

### 💽 Premium Custom Playlists
Create custom playlists with beautifully crafted, high-resolution vector icons (ranging from classic cassettes to minimalist workout and travel themes). 
* **M3U Import Engine:** Seamlessly import your existing `.m3u` playlists with smart file-path matching.
* **Atomic State Updates:** Zero-lag UI rendering with real-time database syncing.

## 🛠️ Tech Stack & Architecture
Melodika is engineered using modern Android development standards to guarantee zero UI freezing and maximum performance:

* **Language:** Kotlin
* **Architecture:** Strict MVVM (Model-View-ViewModel)
* **Database:** Room Database (with background thread atomic updates)
* **Concurrency:** Kotlin Coroutines & Flow (100% I/O Safe)
* **UI Components:** RecyclerView with `DiffUtil` for flawless list animations, Custom XML Drawables, Contextual Action Modes.
* **Media:** Direct ID3 Tag Embedding Engine.

## 🚀 How to Install

Currently, Melodika is hosted independently to provide a pure, unrestricted experience. 

1. Navigate to the [Releases](#) section of this repository.
2. Download the latest `melodika-vX.X.X.apk` file.
3. Open the downloaded file.
> **Note:** Since Melodika is an independent project, your device's Play Protect might display an "Unknown Developer" warning. Melodika is completely safe and open-source. Simply tap **More details** -> **Install anyway**.
